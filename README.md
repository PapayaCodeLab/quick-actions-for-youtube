# Quick Actions for YouTube

Clear your watch history and fill your playlists — in one click.

**Chrome Web Store:** coming soon · [Privacy policy](https://papayacodelab.github.io/quick-actions-for-youtube/privacy.html)

## Features

- **One-click delete** — a trash button on every video in your watch history, Liked videos, Downloads and your playlists. *Watch later* also gets a “remove all” button.
- **Pinned playlists** — pin up to 8 playlists. An icon row under every video adds or removes it with one click, and playlists that already contain the video are highlighted. Give each one an icon: 1,791 icons, any emoji, or your own image.
- **Your language** — follows YouTube’s interface language, 48 languages included.

Everything matches YouTube’s own design and works in light and dark mode.

## Privacy

No account, no server, no tracking, no ads. Settings stay in your browser, and nothing is ever sent to the developer. The extension only runs on youtube.com and contains no remote code. → [Privacy policy](https://papayacodelab.github.io/quick-actions-for-youtube/privacy.html)

## Install

**From the Chrome Web Store:** coming soon.

**From source:**

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder.

Settings: right-click the extension icon → **Options**.
